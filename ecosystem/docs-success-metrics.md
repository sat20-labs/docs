# Docs 成功指标

Docs不以页面数量或访问量单独判断成功。每月按以下四类指标复盘，并保留来源和统计窗口：

| 维度 | 指标 |
| --- | --- |
| 正确性 | 失效链接、源码路径错误、状态过期天数、中文/英文不一致数 |
| 可执行性 | Quickstart完成率、测试网操作成功率、用户遇到的首个阻塞、可复核证据覆盖率 |
| 生态转化 | 有效合作申请、外部节点/Indexer、测试网DEX/DAO试点、外部代码或文档贡献 |
| 支持成本 | 重复问题数、因文档错误导致的工单、平均定位时间、FAQ命中率 |

统计必须区分内部测试、外部用户、测试网和主网，不能把自动化访问或内部验收计作生态采用。涉及钱包行为的成功率只记录脱敏事件，不收集助记词、地址全量或AccountSecret。

**页面状态：指标框架已定义；数据采集逐步接入（Framework Defined / Collection Iterating）**
