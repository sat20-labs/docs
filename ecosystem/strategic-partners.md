# 战略合作伙伴

战略合作围绕可验证交付，不以名称背书或代币价格为目标。

| 类型 | 可验证合作 |
| --- | --- |
| 交易平台/钱包 | L1/L2资产查询、充值提现、STP安全边界、钱包授权与异常恢复 |
| 基础设施 | 独立节点、Indexer、Explorer、RPC、监控和安全运维 |
| BTC社区/流动性 | 测试网市场、资产核账、用户教育和真实使用反馈 |
| 研究/安全 | 协议评审、威胁模型、审计、形式化或差分验证 |
| 生态基金/赞助方 | 有里程碑、预算、披露和验收证据的公共品支持 |

每项合作先定义网络、范围、责任人、数据与资金边界、交付物、验收、公开程度和退出机制。基金会尚未成立，合作不得暗示未存在的基金会授权或固定回报。
