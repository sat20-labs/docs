# GAS：网络费用与安全资产

GAS 是聪网计划用于网络费用与节点质押的资产。它连接网络使用、节点服务和长期安全。

## GAS 用于什么

1. 支付交易费用。
2. 支付智能合约执行费用。
3. 为网络资源定价。
4. 防止滥用。
5. 支持挖矿节点和核心节点的安全质押设计。

## GAS 不是什么

1. GAS 不代表 SAT20 Labs 或未来基金会股权。
2. GAS 不代表利润分配、回购或固定收益承诺。
3. 节点质押不是固定理财产品。
4. 官网和 Docs 不提供价格预测、收益率或交易所路线承诺。
