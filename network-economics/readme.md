# 网络经济

网络经济部分解释Gas计量、测试网SGAS、费用流、节点质押、节点激励和仍在设计中的经济参数。运行时代码已经执行交易/合约费用和Autopay扣费；这不代表正式GAS发行、分配、质押和治理规则已经定稿。

## 核心区分

| 概念 | 含义 |
| --- | --- |
| Gas Unit | 计算、存储和执行资源的计量单位 |
| GAS 资产 | 购买 Gas Unit、支付交易费并用于节点质押的协议资产 |

## 当前设计约束

1. 正式GAS资产计划由BTC L1上的协议发行；测试网使用SGAS验证费用流程，二者不能混同。
2. 总量固定。
3. 通过 Transcend / STP 进入聪网。
4. Gas计量和费用扣除已有实现，用于交易、智能合约及DKVS Autopay等服务验证。
5. 挖矿节点与核心节点计划使用 GAS 作为质押物。
6. 合约和交易产生的 GAS 费用当前设计为归出块节点。
7. 当前费用设计不采用基础费销毁。

正式发行、质押、处罚、开放节点准入、初始分配、基金会治理和法律安排仍在设计中。测试网余额、Faucet和每区块Autopay支付不能作为正式供应或经济模型证据。
