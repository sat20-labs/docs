# 部署社区 DAO

当前Wallet SDK保留DAO通道合约运行时，包含UID、推荐关系、donation与airdrop等状态处理；但这不等于聪网智能合约模板目录已经开放DAO，也不等于PWA当前有公开的一键部署流程。

## 当前可做与不可做

- 可以：在源码测试和受控测试网中验证既有DAO运行时、调用历史与资产结算。
- 不可以：把历史运行时描述成当前公开PWA产品；没有登记合约地址、资产、peer、部署tx和验收记录时，不应引导用户转入资产。
- 新实现应优先明确采用“通道合约”还是“聪网智能合约模板”，不能复用同一个DAO名称混淆两套执行模型。

## 开放部署前门禁

1. 固定合约类型、资产和治理语义，说明UID、捐献、推荐和空投是否仍属于发布范围。
2. 提供部署/调用API、权限、费用、退款与关闭规则。
3. 在虚拟网络和真实测试网验证部署、重复调用、部分失败、回滚/重放与资产核账。
4. PWA提供明确授权页，Explorer/Indexer能够查询调用与结果。
5. 发布经审核的合约登记表和风险说明后，再把本页升级为可执行Quickstart。
