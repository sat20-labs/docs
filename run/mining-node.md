# 挖矿节点

挖矿节点负责聪网的出块、交易排序和合约执行。它是网络执行能力和费用流的基础角色。

节点软件与出块路径已经实现并运行；以下事项分成“实现能力”和“开放参与规则”，不能因为准入/经济参数仍在设计就把节点软件整体标为未实现。

## 仍需公开回答的问题

1. 挖矿节点做什么。
2. 如何参与出块。
3. 如何选择出块者。
4. GAS 质押的作用。
5. 节点可以获得哪些实际网络费用。
6. 服务器、带宽、在线率和安全要求。
7. 如何加入测试网。
8. 如何升级和退出。
9. 哪些处罚规则仍在设计中。

## 当前边界

节点费用来自实际网络服务，不是固定收益产品。现有主网/测试网节点并不意味着第三方已经可以无需审批加入出块；完整质押门槛、处罚规则、解除质押时间和开放准入流程仍在设计中。
